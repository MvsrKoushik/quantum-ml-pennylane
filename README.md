# Quantum ML with PennyLane

The exploratory PennyLane Colab distilled into deterministic feature scaling and a variational-circuit factory. The quantum dependency is optional; the data path can be tested without a simulator.

```bash
pip install -e .[quantum,dev]
pytest
```

This repository is an educational small-data experiment. Classical baselines, seeds, circuit depth, shot count, and optimizer settings should be reported with every result.
